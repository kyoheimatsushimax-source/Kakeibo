# かんたん家計簿

シンプルで一目で分かる、ブラウザだけで動く家計簿アプリ。タブで「ダッシュボード / フロー / ストック」を切り替えます。

## 特徴

- **インストール不要**: `index.html` をブラウザで開くだけ
- **ダッシュボード**: 収入・支出・収支・貯蓄率のKPI (前月比つき)、収入/支出のドーナツ、カテゴリ別月別推移、年間推移、年末着地予測
- **変動費の合計表示**: ダッシュボード上部とフロータブに「変動費 合計 (固定費以外すべて)」を大きく表示。内訳はクレカ + 手入力 + 変動費項目、固定費との比率バー、前月比つき。変動費 + 固定費 = 支出
- **フロー**: 固定費/変動費項目を項目別入力 (ドラッグ並べ替え可、固定費は翌月へ自動引継)
- **小遣いの自動計上**: K小遣い・C小遣いを毎月 ¥100,000 ずつ固定費として自動計上 (翌月以降へ自動引継)。金額を変えたい月はフロータブで修正すると以降にも反映
- **ストック**: 預金/投資/負債の口座ごとに「今月末残高」を入力 (前月末残高と前月からの増減は自動表示)。通貨 (JPY/USD/SGD) + 月次為替で円換算。資産配分・純資産推移チャート、口座間の振替記録
- **クレカ CSV インポート**: 利用者をカード番号で自動判定、店舗名から分類を自動判別 (手動修正・ルール記憶も可)、返金(マイナス)対応、大型支出の警告
- **明細**: 検索・ソート・編集・削除 (削除はUndo可)
- **データはローカル保存**: `localStorage` に保存、外部送信なし
- **完全バックアップ**: 明細・フロー・ストック・分類ルール・表示設定をまとめてJSONでエクスポート/インポート

## 使い方

1. `index.html` をブラウザで開く
2. 上部タブで画面を切替、`‹ ›` または キーボードの `←` `→` で月を移動
3. ダッシュボードの「記録を追加」で収入/支出を入力、クレカは CSV を取込

## カテゴリ

- **収入**: 給与(K)・給与(C)・賞与(K)・賞与(C)・補助金(保育料/児童手当/区手当)
- **支出/クレカ分類**: 食費・外食・日用品・交通・娯楽・旅行・光熱費・子ども関連・医療・通信・美容・K小遣い・C小遣い・C立替・K立替・その他

## 負担と利用者

- **負担**: 家族 / K / C / 立替 (デフォルト家族)。家族のみ全体集計に含む。K・Cは個人別として別集計、立替はどちらの集計にも含めない
- **利用者**: K / C (クレカのカード番号末尾で自動判定)

## クレカ明細インポート

- 利用明細 CSV (.csv) をドラッグ&ドロップ。文字コードは UTF-8 / Shift_JIS 自動判定
- 日付・金額・店舗を自動検出、カード番号で利用者(K/C)、店舗名で分類を自動判別
- マイナス金額(返金)は相殺、平均の3倍以上の大型支出は⚠で強調
- 重複 (日付+金額+店舗) は自動スキップ。負担・利用者・分類を取込後に修正していても重複と判定。店舗名の全角/半角・空白の揺れは同一視。同日同額同店舗の正当な複数件は件数で判定
- 「🧹 重複明細をチェック」で既存の重複を一覧→一括削除 (手で修正した明細を優先して残す。削除直後はUndo可。チェックを外した組は以後警告しない)
- JSON明細の「追加」読込でも、同じIDの明細は二重登録しない
- プレビューで利用者・分類を確認/修正してから一括登録

## 変動費・固定費の考え方

- **固定費** = フロータブの「固定費」項目の合計 (家賃・学費・小遣いなど) + 手入力した「K小遣い/C小遣い」明細 (家族負担)
- **変動費** = 固定費以外すべて = クレカ(家族負担) + 手入力の支出(家族負担) + フロータブの「変動費項目」
- 負担がK/C/立替の明細は、従来どおり家族の集計に含まれません
- 支出 (ダッシュボードKPI・年間推移・カテゴリ別) には、固定費と変動費項目の両方が含まれます

## 小遣いの自動計上

- 初回起動時に固定費項目「K小遣い」「C小遣い」を作成し、起動した月から ¥100,000 を設定します (以後の月は自動引継)
- その月に手入力の「K小遣い/C小遣い」(家族負担) がすでにある場合は、二重計上を避けて翌月から開始します
- すでに同名の固定費項目に金額がある場合は変更しません
- 項目を削除すれば自動計上は止まります (再作成はされません)

## PWA

- `sw.js` を追加 (ネット優先・オフライン時のみキャッシュ)。ホーム画面追加でオフライン起動が可能です

## 財形貯蓄 (給与(K)は天引き後の手取り)

- 給与(K)は財形天引き**後**の手取りで記録します。天引き額 (初期値 ¥50,000/月) は収入にも支出にも足しません
- **貯蓄率(財形込み)** = (収支 + 財形) ÷ (収入 + 財形)。給与(K)の記録がある月だけ財形を加算します (ダッシュボード)
- **ストック**: 「財形」を名前に含む預金口座 (なければ「財形貯蓄」を新規作成) に、翌月分から毎月の天引き額を自動積立。実残高を入力した月はその値で上書きされ、以降はそこから積み上がります
- 天引き額の変更はフロータブの「財形貯蓄」カードで行います (全期間に適用)

## ストックの入力方法 (月末残高を入力)

- 口座一覧の「今月末残高」欄に、通帳やアプリの残高をそのまま入力します。前月からの増減 (金額・%) は自動計算です
- 点線の欄は未入力で、前月末の残高を引き継いで表示しています。入力を消すと未入力に戻ります。口座一覧の見出しに「入力済み n/N」を表示します
- Enter / Tab で次の口座の残高欄へ進みます
- サマリ (預金・投資・負債・純資産) と区分ごとの合計に前月比を表示します。外貨口座は前月末を前月のレートで円換算するため、円ベースの前月比には為替変動が含まれます
- 負債は増加を赤、減少を緑で表示します
- 保存形式 (月末残高のスナップショット) は従来と同じで、過去データはそのまま使えます

## 支出の見直しにつなげる機能

### 予算 (ダッシュボード)

- 変動費のカテゴリごと、および「変動費合計」に月の上限を設定します。実績 / 予算、残り、超過額をバーで表示します
- 当月は「残り日数で1日あたりいくら使えるか」と「着地見込み」を表示します。着地見込み = 今日までの明細 ÷ 経過日数 × 月の日数 + フロータブの変動費項目 (月額はそのまま)
- クレカ明細をまだ取り込んでいない期間の利用分は実績に入らないため、着地見込みは低めに出ます
- 「未設定分を直近平均で埋める」は、直近6か月 (明細のある月) の平均を1,000円単位に切り上げて設定します。平均は現状維持の水準なので、削りたいカテゴリは下げてください
- 手入力の「K小遣い / C小遣い」は固定費扱いのため予算の対象外です

### 見直し候補 (ダッシュボード)

- 直近6か月 (家族負担の支出明細がある月のみ) の平均と比べ、3,000円以上かつ10%以上上振れしているカテゴリを、差額の大きい順に3件まで表示します
- 当月は月途中の実績で比較します (すでに平均を超えたカテゴリだけが出ます)

### 店舗別ランキング・定期課金 (ダッシュボード)

- 店舗別: メモ (店舗名) ごとに家族負担の支出を集計し、上位10店を表示。期間は 今月 / 直近3か月 / 直近12か月。店舗名は全角半角・空白の揺れを同一視します
- 定期課金: 直近6か月のうち3か月以上、月1回・金額のばらつき15%以内で請求があり、直近2か月に請求があった店舗を表示。月額・年額換算・値上げ・今月未請求を表示します。年払い、金額が毎月変わるもの (光熱費など) は対象外です

### 固定費の年額と見直し月 (フロータブ)

- 固定費の各項目に年額 (表示月の金額 × 12) と最終見直し月を表示します。契約やプランを確認したら「見直した」を押すと当月が記録されます
- 未見直し、または最終見直しから12か月以上たった項目は件数と年額合計を警告表示します

### フローとストックの突合 (ストックタブ)

- 純資産の増減 = (収支 + 財形) + 投資の評価損益 + 為替の影響 − 使途不明金
- 使途不明金 = (収支 + 財形) − (預金の増減 + 投資への入金 − 負債の増減)。いずれも為替の影響を除いた額です
- 投資口座は「今月の入金額」(積立・買付。出金はマイナス) を入力すると、評価損益 = 残高の増減 − 入金額 として分離します。未入力なら増減すべてを評価損益として扱います。「振替を記録」で投資口座を指定した場合は入金額にも自動反映します
- 為替の影響 = 前月末残高 × (今月のレート − 前月のレート)
- 差額が max(1万円, 収入の2%) 以内なら「ほぼ一致」と判定します
- 対象外: 今月追加した口座 (前月末残高がない)、為替レート未設定の口座。ただし今月追加した投資口座に「今月の入金額」を入れた場合は、前月末0円からの買付として対象に含めます (預金から新しい投資口座へ資金を移した月は、買付額を入金額に入力してください)
- 直近6か月の推移を表で表示します
- 差が出やすい原因: クレカの利用月と引落月のずれ (未払い残高を負債口座として登録すると解消)、負担がK・C・立替の明細、記録漏れ、未登録口座との資金移動

### ふるさと納税・特別支出

- 支出の分類に「ふるさと納税」「特別支出」を追加しました。クレカ明細は明細一覧の分類プルダウンで、手入力は「記録を追加」のカテゴリで選びます
- この2つは支出・変動費・収支には含めます (現金は実際に出ているため、ストックとの突合が合います)。一方、「変動費合計」の予算、見直し候補、着地見込みからは除きます
- ダッシュボードの変動費カードに「変動費のうち特別支出」と、それを除いた金額を表示します
- 店舗名に ふるなび / さとふる / ふるさとチョイス / ふるさと納税 などを含むクレカ明細は、取込時に自動で「ふるさと納税」に分類します。既存の明細で分類が「その他」のものは、初回起動時に一度だけ自動で付け替えます
- 「特別支出」は、家電の買い替えや冠婚葬祭など、毎月の暮らしの費用と分けて見たい単発の支出に使います

### Claudeで分析 (ダッシュボード)

- 表示月を終点とした直近3 / 6 / 12 / 24か月の集計データを、分析の依頼文つきのテキスト (Markdown) で作成します。「作成してコピー」でクリップボードへ、「ファイルで保存」で .md ファイルとして出力します
- Claudeのチャットに貼り付ける (またはファイルを添付する) と、傾向の分析や見直しの提案を受けられます。アプリからの自動送信はしません
- 含まれる内容: 月別の収支・貯蓄率、収入の内訳、変動費のカテゴリ別月別、固定費の項目と見直し状況、予算と実績、定期課金、店舗別上位20、単発の大きい明細上位15、個人負担・立替、ストックの推移、フローとストックの突合、口座別残高
- 「店舗名・口座名・メモを含める」を外すと、店舗別と大きい明細の表を省き、口座名を「預金1」などに置き換えます (固定費の項目名とカテゴリ名は残ります)
- 明細のない月は表から除き、月途中の当月には * を付けます
- 「Claudeへの補足」に書いた内容 (例: 半年払いの費用がある月) は保存され、毎回の出力の前提に含まれます
- 固定費は支払った月に全額を計上します (月割りしません)。出力には固定費の項目別・月別の表が入るので、半年払い・年払いの月はそこで判別できます
- 記録を追加する日付の初期値が、午前9時より前は前日になる不具合を修正しました

## データについて

- 予算は `budgets`、固定費の見直し月は `flow.items[].reviewed`、投資口座の入金額は `assets.contrib` に保存され、完全バックアップとクラウド同期の対象です。既存データの形式は変えていません
